# Human screen-reader accessibility review

Priority: P2  
Owner: unassigned  

## Problem

Automated accessibility checks cannot establish real screen-reader usability.

## Scope

- Have a screen-reader user assess announcements, focus order, errors, dialogs,
  and dynamic dashboard workflows.

## Acceptance criteria

- Findings, severities, and remediation decisions are recorded.
- Each material finding is linked to an existing or newly planned task.

## Validation

Record test cases, outcomes, and follow-up task links without placing personal
or guild-private content in the repository.
